# 已知人脸图片文件夹
# Known Faces Directory

## 使用说明

将需要识别的人物照片放在此文件夹中。

### 照片要求：

1. **文件命名格式**：
   - 文件名即为识别时显示的人名
   - 例如：`张三.jpg`、`zhang_san.png`、`John_Doe.jpeg`

2. **照片质量要求**：
   - 清晰的正面照
   - 光线充足
   - 人脸占据图片较大比例
   - 最好是单人照片（如果有多人，会使用第一张检测到的人脸）

3. **支持的格式**：
   - `.jpg` / `.jpeg`
   - `.png`
   - `.bmp`

### 示例文件结构：

```
known_faces/
├── 张三.jpg
├── 李四.png
├── wang_wu.jpeg
└── README.md (本文件)
```

### 照片来源建议：

- 身份证照片
- 证件照
- 清晰的自拍照
- 高质量的生活照

### 注意事项：

- 每个人准备1-3张不同角度的照片可以提高识别准确率
- 同一个人的多张照片可以命名为：`张三_1.jpg`、`张三_2.jpg`
- 避免使用模糊、侧脸、戴口罩、戴墨镜的照片
